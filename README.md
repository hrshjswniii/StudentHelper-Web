🎓 College Helper Website

**College Helper** is a simple web application designed to help students manage their academic life in one place. It provides tools for organizing notes, tracking tasks & deadlines, and saving important links — all through a clean and intuitive dashboard.


## ✨ Features

### 🔐 Authentication

* User registration and login system
* Secure access to personal dashboard
* Session-based navigation

### 📊 Dashboard

* Personalized welcome message
* Quick overview of activity
* Statistics for notes, tasks, and links
* Upcoming deadlines section
* Recent activity tracking

### 📝 Notes Manager

* Upload study materials (PDF, DOC, DOCX, TXT, etc.)
* Optional title and description
* Search uploaded notes
* Sort notes (e.g., newest first)
* Track total storage used

### ✅ Tasks & Deadlines

* Add assignments and important tasks
* Set subject and due date
* Assign priority levels
* View and manage active tasks

### 🔗 Important Links

* Save frequently used college portals and resources
* Categorize links
* Quick access anytime
